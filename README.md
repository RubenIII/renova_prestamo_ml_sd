Proyecto de Machine Learning para la renovación de préstamos.
Fecha Inicio: 15/08/2026
Autor: Rubén Coloma

## Objetivo

Desarrollar un modelo de Machine Learning capaz de apoyar la predicción
relacionada con la renovación de préstamos.

## Estructura del proyecto

```text

src/          Código fuente

reports/      Reportes y resultados
```
